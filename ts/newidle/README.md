# NewIdle

A small plugin for Vencord/Equicord that contains several functions of different.

Features:
- Allows you to configure the time of your inactivity at the PC (default is 10 min), after which the discord will automatically switch your status to `Idle`.
- Automatically changes your status to `Idle` if you start the game and your status was `Online` before. This can be disabled in the plugin settings.
- Automatically resets the `Idle` status to `Online` when you start Discord, in case you have a previous state when you restart Discord. You can also disable it in the plugin settings.
